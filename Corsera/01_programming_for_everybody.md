# Programming for Everybody (Getting Started with Python)

- Official Coursera page: https://www.coursera.org/learn/python
- Provider: University of Michigan
- Skill level: Beginner

## Why it fits `~/pythons`

This is the cleanest foundation course for the workspace. It is useful if you want a reset before working in:

- `automation/`
- `apis/`
- `tools/`
- `projects/`

## What it gives you

- first-principles Python syntax
- variables and basic control flow
- a practical on-ramp to the rest of the Python ecosystem

## Best use

Use this if you want to refresh fundamentals before moving into scripts, data work, or automation.
