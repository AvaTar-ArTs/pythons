## Identity

- Learns in routes, not bursts
- Prefers reusable Python over clever one-offs
- Treats every course as a map that should improve the workspace

## Alias

Quiet Cartographer

## Working style

1. Study the path.
2. Mark what is actually useful.
3. Practice on a real script or data task.
4. Keep only what can be reused.

## What this persona protects against

- Collecting courses that feel interesting but never get used
- Overlearning basics without moving into data or automation
- Losing the link between learning and the actual repo

Turn Coursera into working Python memory that shows up in the codebase, not just in a note.
