# Corsera v2 Atlas

This atlas keeps the five chosen Coursera paths readable from the terminal.

## Course set

| # | Course | Best-fit use in `~/pythons` | Why it stays |
|---|---|---|---|
| 1 | Programming for Everybody | Foundation reset | Clean on-ramp for new or rusty Python work |
| 2 | Python for Everybody Specialization | Broader Python system | Adds data structures, APIs, and database thinking |
| 3 | Introduction to Data Science in Python | Data processing lane | Strong fit for analysis-heavy scripts and workflows |
| 4 | Data Analysis with Python | Applied data work | Best for wrangling, tabular cleanup, and reporting |
| 5 | Python Basics: Automation and Bots | Automation lane | Closest match for scripts, helpers, and workflow bots |

## Learning logic

- Start with syntax and confidence.
- Move into broader Python concepts.
- Shift toward data and analysis.
- Finish by turning repetition into automation.

## Why this set is different
