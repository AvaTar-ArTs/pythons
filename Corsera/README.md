# Corsera Picks for `~/pythons`

This folder holds a curated set of five Coursera learning paths that match the current shape of the Python workspace.

Selection goal:
- keep the courses that support the repo’s real work
- avoid generic or redundant learning
- bias toward Python fundamentals, data analysis, automation, and API-friendly workflows

## The 5 picks

1. [Programming for Everybody (Getting Started with Python)](01_programming_for_everybody.md)
2. [Python for Everybody Specialization](02_python_for_everybody_specialization.md)
3. [Introduction to Data Science in Python](03_introduction_to_data_science_in_python.md)
4. [Data Analysis with Python](04_data_analysis_with_python.md)
5. [Python Basics: Automation and Bots](05_python_basics_automation_and_bots.md)

## Why these five

- They cover the repo’s biggest lanes: `data_processing/`, `automation/`, `apis/`, `tools/`, and utility scripting.
- They move from beginner foundations into practical work that maps to the existing workspace.
- They avoid broad courses that would not pay off quickly inside `~/pythons`.

## Suggested order

If you want a simple progression:

1. Programming for Everybody
2. Python for Everybody Specialization
3. Introduction to Data Science in Python
4. Data Analysis with Python
5. Python Basics: Automation and Bots

## Note

Course catalogs and module names can change on Coursera over time. The links in this folder point to the official Coursera pages used for the selection.
