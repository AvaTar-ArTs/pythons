# Coursera Keep / Remove Checklist for `~/pythons`

Based on the current shape of the repo, the strongest learning lanes are Python fundamentals, data analysis, automation, APIs, and practical scripting. The goal here is to keep only the Coursera lanes that map to work you would actually reuse in this workspace.

## Keep

- [ ] **Programming for Everybody (Getting Started with Python)**  
  Keep if you want a clean Python foundation or a refresher before diving deeper into the repo’s automation and utility scripts.

- [ ] **Python for Everybody Specialization**  
  Keep if you want a broader Python base that includes data structures, APIs, databases, and practical programming concepts.

- [ ] **Introduction to Data Science in Python**  
  Keep if you want a strong match for the repo’s `data_processing/` and analysis-heavy scripts. This is one of the best fits for the current workspace.

- [ ] **Data Analysis with Python**  
  Keep if you want a more applied Pandas / NumPy / data-cleaning lane. This fits the repo’s data wrangling and reporting tools well.

- [ ] **Python Data Analytics**  
  Keep if you want a beginner-friendly analytics refresher that aligns with Python-based tables, charts, and structured data work.

- [ ] **Python Basics: Automation and Bots**  
  Keep if you want the most direct match for `automation/`, scripts, and workflow helpers.

- [ ] **Python for Real-World Data Analysis**  
  Keep if you want a practical, project-like data analysis lane that maps to the repo’s inspection and transformation scripts.

## Remove

- [ ] **Generic Python beginner content you already know**  
  Remove if it only repeats basics you can already do comfortably.

- [ ] **Non-Python video learning that does not support this repo’s workflows**  
  Remove if it does not help with automation, data processing, APIs, file operations, or media processing.

- [ ] **Broad career tracks that are interesting but not immediately reusable here**  
  Remove if the course is more about general career development than skills you can apply in `~/pythons`.
