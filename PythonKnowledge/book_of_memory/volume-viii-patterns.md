# Volume VIII: Patterns & Principles

## Core Principles

1. **No primary** — The ecosystem is fluid. Each platform leads when it's the right tool.
2. **Translate, don't copy** — Adapt capability into native format, don't mirror files.
3. **Governance before runtime** — Define what belongs before executing.
4. **Memory compounds** — Every session records what was learned for the next.
5. **Three-layer redundancy** — Primary + fallback + manual for critical systems.
6. **Show evidence** — Never claim done without proof.

## Recurring Patterns

### 1. Fractal Self-Governance
Every platform naturally evolves toward: Governance Doc → Import/Adapt → Runtime → Tracking

### 2. The Agent Cycle
Reflect → Extract patterns → Implement → Record → Repeat

### 3. Session Lifecycle
Startup (load context) → Execute (skill-first) → Periodic (checkpoint) → Exit (save memory)

### 4. The Export Stack
- **Primary**: launchd (every 5 min)
- **Fallback**: cron (every hour)
- **Manual**: ai-export-all

### 5. Memory Hierarchy
- Session (full conversations) → Context (key facts) → Ecosystem (cross-platform map) → Experience (preferences + failures)
