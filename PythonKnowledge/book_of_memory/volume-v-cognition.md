Every platform follows the same emergent pattern — not because one dictates it, but because it works:

```
Governance Doc → Import/Adapt Mechanism → Runtime → Memory/Tracking
```

## The Two Hook Layers (from Qwen's HOOKS_MODEL)

### Layer 1: Bootstrap Hooks (instructional/orchestration)
- Run at session start
- Print rules, discover skills, load baseline behavior
- Example: `superpowers-codex bootstrap`

### Layer 2: Runtime Hooks (event/policy)
- Trigger on pre-tool, post-tool, stop events
- Evaluate policy against actual commands
- Can block, warn, log, or annotate

### Priority Runtime Hooks to Implement
1. Pre-command secret guard
2. Post-command audit annotator
3. Stop-time compliance summary

## The Agent Normalization Pipeline (from Codex)

Codex has a 4-tier system for importing agents:

| Tier | Category | Treatment |
|------|----------|-----------|
| **1** | Engineering roles | Normalize to Codex-ready blueprints |
| **2** | Workflow agents | Convert to checklists/skills |
| **3** | Broad concepts | Distill into bounded instructions |
