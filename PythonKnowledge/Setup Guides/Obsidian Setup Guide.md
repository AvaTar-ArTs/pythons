# Obsidian Setup Guide

## Vault Structure
To maintain a clean knowledge base, we utilize the following directory structure:

- `00 Inbox`: Temporary notes and quick clippings.
- `10 Projects`: Active development documentation.
- `20 Cookbook`: Searchable Python code snippets.
- `30 Knowledge`: Conceptual notes and evergreen topics.
- `40 Archive`: Completed work.
- `90 System`: Templates, scripts, and setup guides.

## Best Practices
- **MOCs (Maps of Content)**: Use index notes to aggregate links to related notes rather than relying on deep folders.
- **YAML Frontmatter**: Always add metadata (tags, creation date, type) to notes for better Dataview querying.
- **Link liberally**: Connect related concepts with `[[WikiLinks]]`.
