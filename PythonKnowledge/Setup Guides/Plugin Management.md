# Plugin Management

## Essential Plugins for Developers

| Plugin | Usage |
| :--- | :--- |
| **Dataview** | Query and aggregate your notes dynamically based on frontmatter. |
| **Templater** | Create project-based note scaffolds using dynamic variables. |
| **Obsidian Git** | Version control for your vault (highly recommended). |
| **Execute Code** | Run Python code blocks directly inside Obsidian for rapid testing. |
| **Omnisearch** | High-performance search optimized for large vaults. |

## Advanced & Developer Tools
| Plugin | Usage |
| :--- | :--- |
| **Custom Frames** | Embed your IDE or terminal right in the Obsidian sidebar. |
| **Advanced Tables** | Better management of CSV-derived data in tables. |
| **Smart Connections** | Uses LLM to create connections between notes based on content. |

## Plugin Configuration
- **Installation**: Use the Community Plugins browser within Obsidian settings.
- **Syncing**: Copy the `.obsidian/plugins` and `.obsidian/community-plugins.json` files when creating new vaults.
- **Independence**: Keep plugin configs separate per vault to avoid setting conflicts.
